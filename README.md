A responsive frontend dashboard developed with **HTML5, CSS3 and JavaScript** to present internship progress, completed tasks, project milestones and technical skill development.

**Key features**
- Responsive desktop and mobile layouts
- Completed task board
- Project milestone timeline
- Skill progress indicators
- Task filtering
- Mobile navigation
- Light/dark theme switching
- Client-side form validation
- Accessibility improvements
- Testing evidence and professional documentation

`Task_1_Industrial_Training_Dashboard/`

### Task 2 — ClarityLoop Decision Journal API

A REST API developed with **Node.js and Express.js** for recording decisions, reviewing outcomes and analysing decision confidence.

**Key areas**
- REST API design
- JSON persistence
- Request validation
- Error handling
- Filtering
- Outcome reviews
- Confidence-versus-outcome insights
- Postman testing
- Automated tests

**Folder:**  
`Task_2_ClarityLoop_API/`

---

### Task 3 — ClarityLoop DB

A database-backed version of ClarityLoop developed using **Node.js, Express.js and Microsoft SQL Server**.

**Key areas**
- SQL Server integration
- Relational database design
- Primary and foreign keys
- One-to-many relationships
- One-to-one relationships
- Many-to-many relationships
- Parameterized SQL queries
- Transactions
- Full CRUD operations
- Validation and Postman testing

**Folder:**  
`Task_3_ClarityLoop_DB/`
