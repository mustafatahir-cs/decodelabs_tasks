# Project 3 Summary

## Title
ClarityLoop DB — Persistent Decision Intelligence API

## Goal
Replace flat-file persistence with a relational SQL Server database and demonstrate database-backed CRUD operations.

## Main Skills Demonstrated
- SQL Server and SSMS
- relational schema design
- primary and foreign keys
- one-to-many relationships
- one-to-one relationships
- many-to-many relationships
- Node.js + Express
- CRUD
- parameterized SQL
- transactions
- validation
- HTTP status codes
- Postman testing
- documentation

## Verified Results
CREATE, READ, UPDATE, DELETE, health checks, relationship queries, Node.js database connectivity, delete verification, and invalid-input validation were manually tested.
