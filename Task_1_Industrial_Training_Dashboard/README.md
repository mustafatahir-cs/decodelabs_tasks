# Industrial Training Dashboard

## DecodeLabs Full Stack Development Internship - Project 1

The **Industrial Training Dashboard** is a responsive frontend web application developed to organise and present internship progress, weekly assignments, project milestones, learning objectives and technical skill development in one structured interface.

The project is built with **semantic HTML5, CSS3 and JavaScript** and is designed to work across desktop, tablet and mobile screen sizes.

## Project Objective

The objective was to strengthen practical frontend development skills by designing and implementing a responsive, interactive and user-friendly internship dashboard.

## Key Features

- Responsive internship dashboard
- Completed task board with filters
- Project milestone timeline
- Skill-progress indicators
- Mobile navigation
- Light/dark theme switcher
- Client-side form validation
- Semantic HTML structure
- Accessibility-friendly labels and ARIA attributes
- GitHub Pages-ready static structure

## How to Run

1. Download or clone the project.
2. Open the folder.
3. Open `index.html` in a modern browser.

No backend server or database is required.

## Testing

The application was tested for responsive layout, task filtering, theme switching, navigation, client-side validation, desktop rendering and mobile rendering.

See `docs/TESTING.md` for the detailed testing record.

## Deployment

The folder is ready for static hosting through GitHub Pages. After adding this task to the DecodeLabs master repository, GitHub Pages can be configured if a public live link is desired.

## Limitation

The project-update form demonstrates **client-side validation only**. It does not transmit or permanently store user data.
